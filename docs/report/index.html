Report content

Every result on FootageCredit links to a file hosted by a third-party archive. We can remove a result from our pages, but the file itself stays on the archive until the archive removes it.

How to report

Use the Report link under any result, or open a report directly. Include the source page link and why it should be removed. For copyright claims, say who owns the work and link to proof of ownership.

We review reports and remove valid ones from search results and topic pages, usually within a few days.

Removing the file at the source

To take the file down everywhere, also contact the archive that hosts it: Wikimedia Commons, Internet Archive, Pixabay, Openverse (removes it from its index; the original host keeps the file).
